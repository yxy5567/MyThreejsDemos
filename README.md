# MyThreejsDemos

用 Three.js / Canvas 做的几个可直接在浏览器打开的网页小游戏。

| 目录 | 游戏 | 说明 |
| --- | --- | --- |
| [`emberspire/`](emberspire/) | 余烬尖塔 | 卡牌 + 爬塔 |
| [`holdem/`](holdem/) | 午夜德州 · Hold'em | 德州扑克 |
| [`midnighthand/`](midnighthand/) | 午夜之手 · Midnight Hand | 卡牌 |
| [`vampiresurvival/`](vampiresurvival/) | 夜幕幸存者 | 幸存者类 Roguelike |

## 运行

纯静态页面，无需构建。直接双击各目录下的 `index.html`，或在仓库根目录起一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。
